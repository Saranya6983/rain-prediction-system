# 🌧️ AI Rain Prediction System

## 📌 Project Overview
This project predicts whether rain will occur using Machine Learning.

The system also:
- Fetches live weather data
- Predicts rain probability
- Shows forecast trends
- Visualizes weather data

---

## 🚀 Features
✅ Live Weather API Integration  
✅ AI Rain Prediction  
✅ Forecast Temperature Trends  
✅ Interactive Dashboard  
✅ Data Visualization  

---

## 🛠️ Technologies Used
- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- Plotly
- OpenWeather API

---

## 📊 Machine Learning Model
Model Used:
- Random Forest Classifier

Accuracy:
- 81%
